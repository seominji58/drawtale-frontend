# 화면 설계서

그림 기반 참여형 이야기 구성 서비스 · Frontend

| 항목 | 내용 |
|---|---|
| 문서 버전 | v0.2 |
| 변경 사항 | 6장을 요소 단위 정의로 확장. 공통 컴포넌트 장 신설 |
| 담당 | Frontend·UX |
| 기준 플랫폼 | 웹 / 태블릿 가로 1024×768 기준, 세로 및 데스크톱 대응 |
| 대상 범위 | 8주 MVP. 사람형 캐릭터 1명, 4장면 이야기, 모션 3~5종 |

---

## 1. 이 문서가 다루는 것

화면 단위의 구성 요소, 요소별 동작과 상태, 서버 연동 지점, 예외 처리를 정의한다. 시각 스타일과 브랜드 디자인은 별도 가이드에서 다룬다.

### 요소 번호 규칙

`화면ID-일련번호` 형식을 쓴다. 예를 들어 S-05-03은 캐릭터 확인 화면의 세 번째 요소다. 공통 컴포넌트는 `C-`로 시작하고 모든 화면에서 같은 번호를 유지한다.

---

## 2. 공통 설계 원칙

| 원칙 | 내용 |
|---|---|
| 한 화면 한 질문 | 한 화면에 선택을 요구하는 요소는 하나만 둔다 |
| 글자 없이도 진행 | 질문과 선택지는 아이콘·음성 중심, 글자는 보조 |
| 자동 전환 금지 | 아이가 눌러야 다음으로 이동 |
| 위치 고정 | 되돌리기 좌상단, 다시 듣기 우상단 고정 |
| 되돌리기는 항상 있다 | 시작 화면과 분석 대기 화면을 제외한 모든 화면에서 제공 |
| 터치 타깃 | 최소 88×88px, 간격 최소 24px |
| 모션 절제 | 전환 200~300ms, 장식용 움직임 없음 |
| 소리는 끌 수 있다 | 어른 설정에서 음성 전체 끄기 가능 |
| 실패를 아이 말로 | 오류 화면에 기술 용어 노출 금지 |

### 2.1 지원 수준

| 항목 | Level 1 | Level 2 | Level 3 |
|---|---|---|---|
| 한 화면 선택지 수 | 2 | 4 | 6 |
| 아이콘 한 변 | 160px | 128px | 104px |
| 아이콘 아래 글자 | 없음 | 있음 | 있음 |
| 질문 음성 자동 재생 | 자동 | 자동 | 버튼으로만 |
| 선택 후 확인 단계 | 있음 | 없음 | 없음 |

## 3. 공통 컴포넌트

```
┌──────────────────────────────────────────────────────┐
│ [C-01]            ● ○ ○ ○                  [C-02]   │  상단 72px
├──────────────────────────────────────────────────────┤
│                     C-03                             │
│                  콘텐츠 영역                          │
│                                                      │
├──────────────────────────────────────────────────────┤
│                  [   C-04   ]                        │  하단 120px
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| C-01 | 되돌리기 | 아이콘 버튼 88px | 기본 / 눌림 | 이전 화면으로 이동. 진행 중 선택값은 유지한다. 첫 화면과 분석 대기 화면에서는 숨긴다 | 없음 |
| C-02 | 다시 듣기 | 아이콘 버튼 88px | 기본 / 재생 중 | 현재 화면의 질문 또는 문장을 다시 읽는다. 횟수 제한 없음. 재생 중 다시 누르면 처음부터 | 없음 |
| C-03 | 전체 진행 표시 | 표시 | 4점 중 현재 위치 | 그림 → 친구 → 이야기 → 놀이 네 구간을 나타낸다. 숫자를 쓰지 않는다 | 없음 |
| C-04 | 다음 | 큰 버튼 | 활성 / 비활성 | 비활성일 때도 누를 수 있고, 누르면 200ms 흔들림으로 아직 선택이 안 됐음을 알린다 | 없음 |
| C-05 | 연결 끊김 띠 | 표시 | 숨김 / 노출 | 상단 6px 띠. 진행 중 작업은 중단하지 않고 재연결을 시도한다 | 없음 |
| C-06 | 대기 표시 | 표시 | 숨김 / 노출 | 500ms 미만 작업에는 띄우지 않는다 | 없음 |

### 3.1 버튼 상태 정의

| 상태 | 처리 |
|---|---|
| 기본 | 불투명도 100% |
| 눌림 | 96% 축소, 100ms |
| 비활성 | 불투명도 40%, 누르면 흔들림 안내 |
| 처리 중 | 라벨 유지, 우측에 작은 표시. 연타는 300ms 차단 |

### 3.2 C-03 진행 구간

| 구간 | 해당 화면 |
|---|---|
| 1 그림 | S-02, S-03 |
| 2 친구 | S-04, S-05, S-06 |
| 3 이야기 | S-07, S-08 |
| 4 놀이 | S-09, S-10, S-11 |

S-07 안에서 장소·문제·행동·결과 네 단계를 나타내는 점은 별도 요소이며 화면 하단에 둔다. 상단 점과 혼동되지 않도록 크기와 위치를 다르게 한다.

## 6. 화면별 요소 정의

### 6.1 S-01 시작

```
┌──────────────────────────────────────────────────────┐
│                                              ①      │
│                                                      │
│                      ②                              │
│                                                      │
│        ┌────────────────┐  ┌────────────────┐       │
│        │       ③       │  │       ④       │       │
│        └────────────────┘  └────────────────┘       │
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| S-01-01 | 어른 설정 진입 | 아이콘 버튼 | 불투명도 40% | 3초 길게 누르면 S-13으로 이동한다. 짧은 탭은 반응하지 않는다. 누르는 동안 테두리가 차오르며 남은 시간을 보여준다 | 없음 |
| S-01-02 | 캐릭터 인사 | 캔버스 | 진입 시 1회 재생 | 탭하면 손 흔들기 모션을 다시 재생한다. 연타는 300ms 차단 | 탭 시 "안녕!" |
| S-01-03 | 이야기 만들기 | 큰 버튼 | 항상 활성 | S-02로 이동한다 | "이야기 만들기" |
| S-01-04 | 내 이야기 | 큰 버튼 | 저장 0건이면 비활성 | S-12로 이동한다. 목록 조회에 실패하면 비활성을 유지하고 오류 화면을 띄우지 않는다 | "내 이야기" |

진입 시 "무엇을 할까요?"를 1회 재생한다. 연동은 `GET /api/stories`의 건수만 사용한다.

```
│ [C-01]            ● ○ ○ ○                  [C-02]   │
│                      ①                              │
│   ┌─────────┐   ┌─────────┐   ┌─────────┐          │
│   │    ②   │   │    ③   │   │    ④   │          │
│   └─────────┘   └─────────┘   └─────────┘          │
│                      ⑤                              │
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| S-02-01 | 안내 제목 | 텍스트 | 고정 | "이런 그림이 좋아요" | 진입 시 자동 |
| S-02-02 | 예시 카드 · 사람 한 명 | 이미지 카드 | 좋음 표시 | 탭하면 전체 화면으로 확대한다. 다시 탭하면 닫힌다 | "사람을 한 명만 그려요" |
| S-02-03 | 예시 카드 · 흰 종이 | 이미지 카드 | 좋음 표시 | 위와 같다 | "하얀 종이에 그려요" |
| S-02-04 | 예시 카드 · 여러 명 | 이미지 카드 | 어려움 표시 | 위와 같다. 부정 표현 대신 "아직 어려워요"로 쓴다 | "여러 명은 아직 어려워요" |
| S-02-05 | 그림 찍기 | 큰 버튼 | 항상 활성 | S-03으로 이동한다 | "그림 찍기" |

Level 1에서는 S-02-04를 숨기고 좋음 예시 두 장만 노출한다. 건너뛰기 버튼은 두지 않는다.

### 6.3 S-03 그림 올리기

```
┌──────────────────────────────────────────────────────┐
│ [C-01]            ● ○ ○ ○                  [C-02]   │
│   ┌────────────────────────────────────┐            │
│   │                 ①                  │            │
│   └────────────────────────────────────┘            │
│      [   ②   ]            [   ③   ]                │
│      [   ④   ]            [   ⑤   ]                │
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| S-03-01 | 미리보기 영역 | 이미지 영역 | 비었음 / 선택됨 | 비었을 때는 점선 테두리와 안내 문구를 보여준다. 선택되면 그림을 채워 넣는다 | 비었을 때 "그림을 찍어 볼까요?" |
| S-03-02 | 찍기 | 큰 버튼 | 선택 전에만 노출 | 태블릿에서는 `capture="environment"`로 카메라를 연다. 데스크톱에서는 파일 선택으로 자동 대체된다. 카메라 권한이 거부되면 이 버튼을 숨기고 S-03-03만 남긴다 | "그림 찍기" |
| S-03-03 | 앨범에서 | 큰 버튼 | 선택 전에만 노출 | 파일 선택 창을 연다. 10MB 초과 또는 미지원 형식은 업로드 전에 막고 안내 문구를 띄운다 | "앨범에서 고르기" |
| S-03-04 | 다시 고르기 | 버튼 | 선택 후 노출 | 미리보기를 비우고 선택 전 상태로 돌아간다 | "다시 고르기" |
| S-03-05 | 이 그림으로 | 큰 버튼 | 선택 후 노출 | 업로드를 시작하고 S-04로 이동한다. 전송 중에는 처리 중 상태로 바꾸고 연타를 막는다 | "이 그림으로 할래요" |
| S-03-06 | 업로드 진행 표시 | 표시 | 전송 중에만 노출 | 업로드 진행률을 띠로 보여준다. 실패하면 E-01이 아니라 이 화면에서 재시도 버튼을 띄운다 | 없음 |

클라이언트에서 긴 변 1600px로 리사이즈하고 JPEG 품질 0.85로 재인코딩한 뒤 전송한다. 원본은 보내지 않는다. 연동은 `POST /api/characters`이며 응답으로 analysisId를 받는다.

### 6.4 S-04 캐릭터 만드는 중

```
┌──────────────────────────────────────────────────────┐
│                   ● ● ○ ○                            │
│                      ①                              │
│                      ②                              │
│                      ③                              │
│                                            [  ④  ]  │
│   ⑤ (진단 모드에서만)                                │
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| S-04-01 | 대기 애니메이션 | 캔버스 | 반복 재생 | 그림이 서서히 또렷해지는 연출. 실제 진행률과 연동하지 않고 일정 속도로 돈다 | 없음 |
| S-04-02 | 안내 문구 | 텍스트 | 고정 | "친구를 만들고 있어요" | 진입 시 1회 |
| S-04-03 | 단계 점 | 표시 | 4단계 | SSE로 받은 `segmenting → estimating_pose → building_skeleton → done`에 맞춰 채운다. 단계 이름은 노출하지 않는다 | 없음 |
| S-04-04 | 그만하기 | 버튼 | 3초 후 노출 | 요청을 취소하고 S-03으로 돌아간다. 진입 직후에는 숨겨서 실수로 누르는 것을 막는다 | 없음 |
| S-04-05 | 진단 정보 | 텍스트 | 진단 모드에서만 | 실제 단계명, 경과 시간, 사용된 엔진 이름을 표시한다. 개발과 발표 시연에 쓴다 | 없음 |

연동은 `GET /api/characters/{id}/events`(SSE)다. 30초를 넘기거나 `ENGINE_TIMEOUT`을 받으면 E-01로 이동한다. 연결이 끊기면 3초 간격으로 두 번 재연결하고 그래도 실패하면 오류로 처리한다. 이 화면에서는 C-01을 숨긴다.

### 6.5 S-05 캐릭터 확인

```
┌──────────────────────────────────────────────────────┐
│ [C-01]            ● ● ○ ○                  [C-02]   │
│                      ①                              │
│              ┌──────────────┐                        │
│              │      ②      │                        │
│              └──────────────┘                        │
│                      ⑤ (조건부)                      │
│        [   ③   ]        [   ④   ]                  │
└──────────────────────────────────────────────────────┘
```

| No | 요소명 | 유형 | 상태 | 동작 및 예외 | 음성 |
|---|---|---|---|---|---|
| S-05-01 | 제목 | 텍스트 | 고정 | "내 친구가 움직여요" | 진입 시 자동 |
| S-05-02 | 캐릭터 캔버스 | 캔버스 | 손 흔들기 반복 | 탭하면 다른 모션을 순서대로 재생한다. 마스크가 없으면 원본 이미지로 렌더하고 그대로 진행한다 | 없음 |
| S-05-03 | 다시 찍기 | 버튼 | 항상 활성 | S-03으로 돌아간다. 직전 그림은 버린다 | "다시 찍기" |
| S-05-04 | 이 친구로 할래요 | 큰 버튼 | 항상 활성 | 캐릭터를 확정하고 S-07로 이동한다 | "이 친구로 할래요" |
| S-05-05 | 어른에게 도움 받기 | 보조 버튼 | 조건부 노출 | `confidence < 0.6`이거나 관절 하나라도 `score < 0.4`이면 노출한다. 누르면 S-06으로 이동한다 | 없음 |

Level 1에서는 S-05-02의 모션을 손 흔들기 하나로 고정한다. 연동은 `GET /api/characters/{id}`이며 마스크와 키포인트를 받아 클라이언트에서 렌더한다.

