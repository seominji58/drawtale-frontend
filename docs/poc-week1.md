# 1주차 PoC 체크리스트

**1주차 끝에 아래 값이 모이면 팀이 정해야 할 것 대부분이 자동으로 정해진다.**
판단 기준은 제안값이므로 팀에서 조정하면 된다.

원본은 통합 정리 문서(`docs/source/한칸이야기_통합정리_기술구조와예산.docx`)의
「1주차 PoC 체크리스트」다. 여기에 **9·10번을 새로 넣었다** — 장면 배경을 언제
만들지 정하려면 실측이 필요해서다 (`docs/open-decisions.md` 7번).

## 엔진과 파이프라인

- [ ] **Docker 기동**
  빌드 후 ping, `docker save`로 이미지 파일 저장
  → *팀 PC 한 대 이상에서 재현되면 통과*

- [ ] **검출 성공률**
  대상 아동 그림 20장 입력
  → *16장 이상 성공이면 그대로 진행*

- [ ] **관절 정확도**
  `joint_overlay.png`를 한 장씩 확인
  → *팔꿈치·무릎이 명백히 틀린 그림 5장 이하*

- [ ] **마스크 품질**
  흰 종이 / 줄 공책 / 그림자 있는 사진 비교
  → *실패 조건을 S-02 안내 문구에 반영한다*

- [ ] **처리 시간**
  CPU에서 검출과 포즈 한 장 소요 시간
  → *5초 이내면 S-04 대기 화면을 그대로 쓴다*

- [ ] **좌표 변환**
  잘라낸 영역 좌표를 프론트 계약으로 변환
  → *S-05에서 실제 그림이 어긋남 없이 움직이면 통과*
  → 관련: `docs/open-decisions.md` 1·2번 (`head` 관절, 좌표 기준)

## 9. 레퍼런스 기반 배경 생성 실측 — 결정 7번 *(새로 추가)*

장면 배경을 미리 만들지, 아이가 이야기를 만들 때 생성할지 정하려면 숫자가 필요하다.
지금은 양쪽 다 추측으로 말하고 있다.

준비물은 `docs/art-direction.md`의 스타일 앵커와, 1단계에서 확정한 배경 한 장
(`bg-forest-0.png`)을 레퍼런스로 쓴다.

- [ ] **장당 소요 시간**
  레퍼런스를 넣고 배경 1장 생성. 요청부터 파일을 받기까지 몇 초인가
  → *아래 10번에서 잰 S-07 선택 시간보다 짧아야 사전 생성이 성립한다*

- [ ] **장당 비용**
  OpenAI 대시보드에서 실제 청구액 확인. **레퍼런스 이미지가 입력 토큰으로 들어가므로
  단가표보다 비싸다**
  → *이야기 1편 = 배경 4장. 1편당 비용 × 8주 예상 편수가 예산 안에 드는가*
  → 비교 기준: A안 352,750원 · C안 385,750원 · D안 674,500원 · **원안 375,000원**

- [ ] **화풍 유지**
  같은 레퍼런스로 같은 장소를 4장(분위기 0~3) 뽑는다
  → *`tools/icon-review.html`에 넣고 한 세트로 보이는지 확인*

- [ ] **부적절 비율**
  위 4장 중 **무섭거나 · 슬프거나 · 아이 그림을 잡아먹는** 것이 몇 장인가
  → *아동 대상이므로 0이어야 한다. 한 장이라도 나오면 자동 판정 장치가 필요하다*
  → 1차 시도에서는 **3장 중 2장이 기준을 벗어났다** (`docs/worklog.md`).
     프롬프트에 `no face` · `still gentle` · `Flat shapes` 가 이미 있었는데도 그랬다

## 10. S-07 선택 소요 시간 — 프론트가 잰다 *(새로 추가)*

9번의 「장당 소요 시간」을 판정하려면 아이가 네 단계를 고르는 데 실제로 얼마나
걸리는지 알아야 한다. 이 시간 안에 생성이 끝나면 **대기가 아예 보이지 않는다.**

- [ ] 목 엔진으로 S-07 네 단계를 실제로 골라 보고 시간을 잰다
  → Level 1 / 2 / 3 각각. **Level 1은 선택마다 확인 팝업(S-07-04)이 있어 가장 길다**
  → 어른이 아니라 **아이가 쓰는 속도**를 가정해야 한다. 가능하면 실제 아동에게

> 근거: 통합 정리 문서가 애니메이션에 대해 이미 같은 패턴을 제안했다 —
> 「캐릭터 확정 직후 아이가 S-07에서 선택하는 동안 뒤에서 미리 렌더하면
> 기다림이 보이지 않습니다.」 배경 생성에도 그대로 적용된다.

다르면 S-02가 아이를 실패로 안내하는 화면이 된다.
