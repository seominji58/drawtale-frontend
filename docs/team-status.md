### 정해진 것 (근거는 `open-decisions.md` 0절)

- **프론트는 React 유지** (2026-10-01). Vue 로 바꿀지 물었는데, 필요한 기능(캔버스 · 터치 · 음성 · 반응형)은 브라우저 기능이라 차이가 없고,
  처음 코드(9/29)부터 React 였으며 팀 문서(최종 인프라 구조 정리)도 React 다. 바꾸면 화면을 다시 짜야 할 뿐이다. 「React 기반 반응형 웹앱」으로 적는다

- **S-03D**: 사진 올리기와 나란히. 선만 있는 도형도 **조각이 서로 닿으면** 인식이 잘 된다 (실측 3~5초, 관절 제자리). 그래서 도장은 늘 몸에 붙은 자리에 찍히고 손 그림은 올리기 전에 이어졌는지 확인한다.
- **S-07**: 네 방식을 목업으로 비교하고(https://claude.ai/artifact/PZBhaLXfEK65sDkuXwhv6w, 비공개 — 공유받아야 열림) **카드 + 말로 덧붙이기 + 안내 나레이션**으로 정했다. 음성 인식은 브라우저 내장, 어른 설정에서 켠다(기본 꺼짐). 아이 말은 백엔드 GPT 가 「~어요」로 다듬고 검열한다. 검열에 걸리면 E-01 「이 이야기는 만들 수 없어요」 → 다시 고르기.
- **이야기 음성**: 백엔드 `TTS_PROVIDER` 로 openai / elevenlabs 를 고른다. 키는 백엔드 `.env` 에만 — 채팅·문서·커밋에 붙이지 않는다.
