# 개인정보 처리방침

**한칸이야기**(이하 「서비스」)는 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

## 1. 가장 먼저 알아야 할 것

이 서비스는 **아이가 보호자와 함께** 쓰는 것을 전제로 만들었습니다 (만 5세부터).
그래서 아이에 관한 정보를 **처음부터 받지 않는 쪽**으로 설계했습니다.

| | |
|---|---|
| **아이는 계정을 만들지 않습니다** | 계정은 만 14세 이상의 보호자 또는 교사의 것입니다 |
| **아이의 나이 · 성별을 받지 않습니다** | 입력란 자체가 없습니다. 이야기 주인공 이름은 아래 2번에 따로 적었습니다 |
| **아이의 목소리를 저장하지 않습니다** | 말하기 기능은 기기 안에서 글자로 바꾸고, 소리는 남기지 않습니다 |
| **아이가 그린 그림은 기본적으로 지웁니다** | 아래 4번 참고 |

## 2. 무엇을 받나요

### 보호자 · 교사에게 받는 것

| 항목 | 언제 | 왜 |
|---|---|---|
| 카카오 또는 구글의 **회원번호** | 로그인할 때 | 다시 오셨을 때 같은 분임을 알아보기 위해 |
| 약관에 동의한 시각과 약관의 판 | 가입할 때 | 동의를 받았다는 기록 |
| 로그인 상태를 나타내는 값 | 로그인할 때 | 매번 로그인하지 않아도 되도록 |
| 보호자 목소리 (원하실 때만) | 「보호자 목소리로 읽어 주기」를 켤 때 | 이야기를 보호자 목소리로 읽어 주기 위해. 녹음 파일은 저장하지 않고 목소리 정보만 둡니다 |

**이름 · 이메일 · 프로필 사진은 받지 않습니다.** 카카오 · 구글에 동의 항목을 요청하지 않으며,
회원번호 외에는 받아 오지 않습니다.

### 아이가 만드는 동안 생기는 것

| 항목 | 설명 |
|---|---|
| 올린 그림 | 사진으로 찍거나 화면에 그린 그림 |
| 관절 위치 | 그림에서 찾아낸 점 15개의 좌표 |
| 고른 네 칸과 만들어진 이야기 | 「숲」 「길을 잃었어요」 같은 선택과 그 문장 |
| 이야기 주인공 이름 | 아이가 캐릭터에 붙인 이름. 실명을 쓰지 않도록 안내합니다 |
| 읽어 주는 음성 · 움직이는 영상 | 이야기로 만든 파일 |
| 순서 맞추기 기록 | 몇 번 만에 맞혔는지, 그때의 지원 수준 |

## 3. 무엇에 쓰나요

받은 정보는 **서비스를 제공하는 데에만** 씁니다.

- 그림에서 캐릭터를 찾아 움직이는 영상을 만드는 데
- 고른 네 칸으로 이야기 문장과 음성을 만드는 데
- 다시 오셨을 때 만든 이야기를 보여 드리는 데
- 아이에게 맞는 지원 수준을 기억하는 데

**광고에 쓰지 않습니다. 다른 곳에 팔지 않습니다.** 모델을 더 똑똑하게 만드는 학습에도 쓰지 않습니다.

## 4. 얼마나 두나요

| 항목 | 기간 |
|---|---|
| **올린 그림 (원본)** | 어른 설정에서 「원본 그림 보관」을 꺼 두면(기본값) **그림을 떠날 때 지웁니다.** 늦어도 **24시간** |
| 그림 분석에 쓴 임시 파일 | 늦어도 **24시간** 뒤 지웁니다 |
| 로그인 상태를 나타내는 값 | **30일**. 로그아웃하면 바로 지웁니다 |
| 관절 위치 · 이야기 · 음성 · 영상 · 순서 맞추기 기록 | 〔정하는 중〕 — 회원은 계정이 있는 동안, 비회원은 일정 기간 뒤 지우는 방향 |
| 보호자 목소리 정보 | 지우기를 누르시거나 계정을 지울 때까지 |

지우기를 요청하시면 **지체 없이 지웁니다** (아래 7번).

## 5. 다른 곳에 보내나요

**아이가 그린 그림은 다른 회사로 보내지 않습니다.**
그림에서 관절을 찾고 영상을 만드는 일은 저희가 운영하는 서버에서 합니다.

| 받는 곳 | 보내는 것 | 무엇에 쓰나 |
|---|---|---|
| Anthropic | 아이가 고른 네 칸의 말, 덧붙인 한마디, 보호자가 적은 문장 | 이야기 대본 만들기 |
| OpenAI | 위와 같은 글자, 만들어진 문장 | 해로운 내용인지 검사. Anthropic 이 답하지 않을 때 대신 대본 만들기 |
| ElevenLabs | 만들어진 문장, 보호자 목소리 녹음 (켤 때만) | 읽어 주는 음성 만들기 · 보호자 목소리 만들기 |
| Microsoft (Azure) | 저장되는 모든 자료 | 서버 운영 (대한민국 중부 지역) |

- 보내는 글자에 **아이의 나이는 들어 있지 않습니다.** 주인공 이름은 그 자리에서 만드는 대본과 읽어 주는 음성에 함께 들어갑니다
- **카드만 골라 만든 이야기는 미리 만들어 둔 것**이라 이때는 이야기 문장을 어느 회사로도 보내지 않습니다
- 각 회사가 받은 내용을 학습에 쓰는지 · 얼마나 보관하는지는 〔확인하는 중〕입니다. 확인되면 이 자리에 적습니다
- 위 외에 **개인정보를 제3자에게 제공하지 않습니다**

## 6. 아이가 그린 그림은 누구 것인가요

**아이 것입니다.** 저작권은 그린 아이에게 있습니다.

서비스는 그림을 **이야기와 영상을 만드는 데 쓰는 범위에서만** 이용합니다.
홍보 · 전시 · 연구 · 모델 학습 등 다른 목적으로 쓰려면 **그때 따로 동의를 받습니다.**
동의하지 않으셔도 서비스를 쓰시는 데 아무 지장이 없습니다.

## 7. 어떻게 지우나요

| 방법 | 어디서 |
|---|---|
| 그림 원본 지우기 | 어른 설정에서 「원본 그림 보관」을 꺼 두면 자동으로 지워집니다 |
| 보호자 목소리 지우기 | 어른 설정 > 보호자 목소리에서 지웁니다 |
| 계정과 모든 자료 지우기 | 〔문의처 — 정하는 중〕로 요청하시면 지웁니다 |

지운 자료는 되살릴 수 없습니다. **아이 화면에서는 지울 수 없도록** 해 두었습니다.

## 8. 안전하게 지키기 위해 하는 것

- 로그인 값은 **원문을 저장하지 않고 되돌릴 수 없는 형태로 바꿔서** 보관합니다
- 그림 · 음성 · 영상은 **짧은 시간만 유효한 주소**로만 열 수 있습니다
- **다른 사람의 그림이나 이야기는 열람할 수 없습니다.** 로그인한 계정의 것만 보입니다
- 서버 기록(로그)에 **그림과 이야기 내용을 남기지 않습니다**
- 외부 서비스에 쓰는 열쇠(API 키)는 서버에만 두고 화면에 내려보내지 않습니다
- 모든 연결은 암호화(HTTPS)됩니다

## 9. 만 14세 미만 아동의 개인정보

만 14세 미만 아동의 개인정보를 동의에 근거해 처리할 때는
**법정대리인의 동의를 받고, 그 동의가 이루어졌는지 확인합니다** (개인정보 보호법 제22조의2).

| | |
|---|---|
| 아이는 직접 가입하지 않습니다 | 계정은 만 14세 이상의 보호자 또는 교사가 만듭니다 |
| 받지 않는 것 | **주민등록번호, 신분증, 아이의 생년월일**은 받지 않습니다 |
| 동의를 확인하는 방법 | 〔정하는 중〕 |

법정대리인은 아이에 관한 자료의 **열람 · 정정 · 삭제 · 처리정지**를 요구하실 수 있고,
**동의를 철회**하실 수 있습니다. 〔문의처 — 정하는 중〕로 연락하시면 지체 없이 처리합니다.

## 10. 생성형 AI 이용 안내

이 서비스는 **생성형 AI 로 이야기 문장과 읽어 주는 음성을 만듭니다.**
만들어진 결과물에는 **AI 가 만들었다는 사실을 표시합니다** (인공지능기본법 제31조).
