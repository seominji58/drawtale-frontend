# 그림 만들기 (B 크레용 화풍, 2026-11-03)

화면 그림(장면 배경판 · 배경 속 물건 · 기본 소품 · 카드 · 삽화 · S-02 예시)을 만드는 스크립트.
키는 `../drawtale-backend-git/.env` 의 `OPENAI_API_KEY` 를 읽기만 한다. **유료(gpt-image-2)이니 돌리기 전에 장수 · 금액을 확인**한다.
생성 원본(PNG)은 저장소에 넣지 않고, 이 폴더 아래 `b-crayon/` · `all/` 에 생긴다(.gitignore).

| 순서 | 스크립트 | 무엇 |
|---|---|---|
| 1 | `gen_layers.py` | 화풍 시험 — 놀이터 배경판 1 + 물건 3 (A 마커 · B 크레용). B 의 배경판이 이후 모든 그림의 화풍 참고 그림 |
| 2 | `gen_all.py` | 나머지 전부 — 배경판 7 · 물건 · 소품 · 인물 기준 그림(cast) · 카드 36 · 삽화 4 · S-02 예시 6. 이미 있는 파일은 건너뜀 |
| 3 | `process.py` | 흰 바탕 오리기(가장자리 + 선으로 둘러싸인 큰 흰 구멍) → `public/` 에 WebP, 장소마다 `public/scenes/{장소}/layout.json`, 장소 카드 합성 |
| 4 | `gen_places.py` · `process_places.py` | 장소 안 세부 장소 21곳 (교실 · 급식실 · 복도 …) — 배경판 + 물건 → `public/scenes/{세부}/`. 실내는 원근 없는 정면 벽 |
| — | `card_fit.py` | 카드 그림을 카드 위쪽 칸 비율(1.55:1)로 — 그려진 곳만 두고 흰 종이로 이어 붙임 |
| — | `compose.py` · `cutout.py` | 오리기 · 좌표대로 쌓기 |
| — | `paper.py` | 아이 그림 사진의 조명 보정 시험 — 종이색을 그림 **바깥** 빈 종이에서 재서 흰색으로 (아이가 칠한 색은 종이 대비 그대로) |

좌표 표(`layout.json`): `x` 가운데, `foot` 발끝(또는 `top` 윗변), `h` 화면 높이 대비 — 모두 0~1. 화면 · 장소 카드가 같은 표를 쓴다.
