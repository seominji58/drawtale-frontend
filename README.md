# 한칸이야기 · Frontend

화면설계서 v0.2 를 그대로 구현한 프론트엔드 골격입니다.
백엔드 없이 목 엔진으로 전체 흐름이 끝까지 돕니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
```

백엔드를 함께 띄울 때는 8000번에 올리면 `/api` 요청이 자동으로 넘어갑니다.

```bash
cp .env.example .env
# VITE_ENGINE=mock | agent | finetuned
```

`mock` 이면 서버 없이 돌아갑니다. 에이전트든 파인튜닝이든 응답 계약이 같으므로
화면 코드는 바뀌지 않고 `VITE_ENGINE` 만 바꾸면 됩니다.

## 화면 디자인

구름과 젤리를 재료로 잡았습니다. 각진 것을 두지 않고, 모서리를 크게 굴리고,
그림자는 회색 대신 자기 색을 머금은 것만 씁니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--milk` | `#F3F6FD` | 바탕 |
| `--cloud` | `#FFFFFF` | 아이 그림이 사는 자리 |
| `--grape` | `#6B7FE8` | 주된 행동 하나에만 |
| `--butter` | `#FFE6A3` | 고른 카드와 읽고 있는 문장 |
| `--c-place` 외 3 | 파스텔 4색 | 이야기 네 단계를 색으로도 구분 |

- 서체는 둘입니다. 질문·제목·버튼은 둥근 **Jua**, 본문과 어른 화면은 **Pretendard**.
- 버튼은 알약 모양이고 아래에 턱이 있습니다. 누르면 그 턱이 사라지면서 폭 내려앉습니다.
- 이징을 `cubic-bezier(.34, 1.4, .5, 1)` 로 두어 살짝 튕깁니다. 아이 손에 반응하는 느낌입니다.
- 바탕에 몽글한 덩어리 둘이 떠 있습니다. 화면에서 유일한 장식이고 나머지는 전부
  기능을 합니다.
- 선택 표시는 버터색으로 칠하고 살짝 커집니다. 색이 아니라 밝기와 크기로 바뀌므로
  색각 특성과 무관하게 보입니다.
- **어른 설정은 3초 길게 누르기**로만 열립니다. 누르는 동안 버튼 둘레에 고리가 차오르고,
  짧게 누르면 「3초 동안 꾹 눌러 주세요」가 잠깐 뜹니다. 아이가 우연히 들어가지 못하게
  하려는 장치라 일부러 어렵게 되어 있습니다.
- 진입 애니메이션은 없습니다. 움직임은 아이가 누른 것에만 답합니다. 대기 화면의
  둥실거림만 예외인데, 기다리는 중이라는 것 자체를 알리는 일을 합니다.

화면은 위 레일, 가운데 무대, 아래 행동 줄 세 덩어리뿐입니다.
`components/Screen.tsx` 가 이 틀을 만들고 각 화면은 무대 안만 채웁니다.

### 버튼 위계

한 화면의 주된 행동은 하나입니다. 로그인·회원가입처럼 곁들이는 선택지는
같은 크기 버튼으로 쌓지 않고 `.aside-links` 글자 줄로 내립니다. S-14 처음 실행은
「바로 시작하기」 하나만 큰 버튼이고, 로그인과 회원가입은 그 아래 한 줄입니다.

### 아이 화면과 어른 화면

같은 틀을 쓰되 밀도가 다릅니다. `<div data-audience="adult">` 가 붙으면 터치 타깃이
88px 에서 60px 로, 글자가 한 단계씩 작아지고, 가운데 정렬이 왼쪽 정렬로 바뀝니다.
S-06 관절 맞추기, S-13 어른 설정, S-14~S-16 이 여기 해당합니다.
교사가 화면을 보자마자 자기 화면인 걸 알 수 있게 하기 위한 구분입니다.

## 그림이 들어갈 자리

실제 일러스트가 아직 없어서 `components/illust.tsx` 에 임시 삽화를 SVG 로 그려 두었습니다.
캐릭터, 그림 종이, 연필, 갸웃하는 얼굴, 축하, 장면 배경 여섯 개입니다.
실제 그림이 준비되면 이 파일만 갈아끼우면 됩니다.

선택지 아이콘은 `api/mock/fixtures.ts` 의 `icon()` 이 임시로 만듭니다.

### 확인용 샘플 그림

그림 없이도 캐릭터가 움직이는 것까지 보려면 **S-03 그림 올리기**에서
「샘플 그림으로 해보기」를 누르세요. `api/mock/sample.ts` 가 목 엔진이 돌려주는
키포인트와 같은 자리에 사람 하나를 캔버스로 그려서 그대로 태웁니다.
목 엔진일 때만 보이는 링크입니다.

## 지원 수준

화면을 세 벌 만들지 않습니다. `styles/tokens.css` 의 CSS 변수와
`store/settings.ts` 의 `LEVEL_CONFIG` 만 바뀝니다.
`<html data-level="1|2|3">` 이 바뀌면 아이콘 크기와 글자 노출이 함께 따라옵니다.

## 계정과 데이터 (설계서 11장)

- 계정은 보호자·교사의 것입니다. 아이는 로그인하지 않습니다.
- 로그인은 앱 첫 실행에만 묻고, 이후에는 바로 S-01 로 갑니다.
- **비회원**: 토큰과 이야기를 `sessionStorage` 에만 둡니다. 탭을 닫으면 함께 사라지고,
  `pagehide` 에서 메모리 상태와 이미지 URL 도 해제합니다. `localStorage` 에는 쓰지 않습니다.
- **회원**: 토큰과 목록을 `localStorage` 에 두고 다음 실행에도 유지합니다.

### 체험 한도 (설계서 11.2)

비회원은 기기당 2편까지 만들 수 있습니다. 세션마다 세그멘테이션·포즈 추정·문장 생성·
음성 합성이 유료 호출로 나가기 때문입니다. 반대로 가입을 앞에 세우면
"내 그림이 움직인다"를 보여주기 전에 사람이 나가므로, 체험은 열되 횟수를 둡니다.

- 횟수는 `store/auth.ts` 의 `TRIAL_LIMIT` 하나로 조절합니다.
- `localStorage` 에는 정수 하나만 셉니다. 이야기 내용과 그림은 남기지 않습니다.
- 만드는 도중에 끊지 않고, S-01 에서 시작할 때만 확인합니다.
- 한도를 다 쓰면 아이 화면에서 막지 않고 S-14 로 보냅니다. 문구가 어른 대상으로 바뀝니다.
- 전환 안내는 S-11 에서 한 번만 띄웁니다.

값을 매길 지점은 저장이 아니라 **내보내기와 여러 아이 관리**입니다. 저장 자체를
유료로 묶으면 인색해 보이기만 하고 전환은 늘지 않습니다.

## 캐릭터 애니메이션

`features/character/skeleton.ts` 가 키포인트에서 뼈대를 만들고 모션을 계산합니다.
`CharacterCanvas.tsx` 는 뼈마다 원본 그림을 사각형으로 잘라 회전시킵니다.
PixiJS 없이 Canvas 2D 의 `clip()` + `drawImage()` 만 씁니다.

관절 이름은 Meta Amateur Drawings 어노테이션을 그대로 따릅니다.
AI 담당자가 내보내는 이름과 어긋나면 변환 레이어가 하나 더 생기므로
`types/character.ts` 를 그대로 계약으로 쓰시면 됩니다.
